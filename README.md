# India Tech Career Intelligence 2026

## Project Title

**India Tech Career Intelligence — Salary, Skills & Hiring Trends Analysis**

## Description

This project analyzes India's technology job market to uncover salary patterns, in-demand technical skills, hiring trends, career opportunities, and location-based insights.

The dataset contains 100,000 technology job records with 33 features covering job roles, technical domains, salaries, experience levels, education, companies, locations, work modes, skills, applicant information, career growth, and other employment-related attributes.

Python is used for data cleaning, preprocessing, exploratory data analysis, and visualization, while Power BI is used to create an interactive dashboard for discovering meaningful business and career insights.

## 🔍 Key Insights

- 💰 Average salary midpoint: **₹849.95K**
- 👨‍💻 **59.9%** of jobs are Mid-Senior roles
- 🌐 Remote + Hybrid jobs: **~79.7%**
- 👥 Total applicants: **~24.69M**
- 📊 Average applicants per job: **~247**
- 📈 Average career growth: **81.51%**
- 🐍 Python and Linux are among the most frequently represented skills
- 📅 February recorded the lowest job postings at **18.8K**
- 📈 Job postings recovered to **20.5K in March**
- 🔎 The February decline was broad-based across major categories, technical domains, locations, and experience levels
